스레드 레이스 — 메인이 막히면 누가 멈추나

같은 애니메이션, 다른 CSS 속성. 메인 스레드를 점유하면 한쪽만 멈춘다. 아래 스트립차트는 실제 프레임 간격을 그린 것이라, 막히는 순간이 그래프에 그대로 남는다.

메인 스레드 정상

left 레이아웃 필요

매 프레임 Layout → Paint → Raster 를 다시 돈다. 메인 스레드가 막히면 정지.

transform 컴포지터

Layout·Paint 를 건너뛰고 합성만 한다. 메인 스레드와 무관하게 계속.
