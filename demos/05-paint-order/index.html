DEMO 05

paint order — DOM 순서대로 그리지 않는다

요소를 눌러 고른 뒤 속성을 켜보면 그리는 순서가 재배열된다. 오른쪽 목록이 실제 paint order 다. z-index 뿐 아니라 opacity·transform·filter 도 스택 컨텍스트를 만든다.

선택: A

실제 paint order (위 → 아래 = 먼저 → 나중)

    —

    paint phase — 각 phase 가 스택 컨텍스트를 따로 순회한다

    backgrounds
    floats
    foregrounds
    outlines

    A1 실측에서 Paint 이벤트가 요소 수보다 훨씬 많은 이유 — 같은 요소를 phase 마다 다시 방문한다.
