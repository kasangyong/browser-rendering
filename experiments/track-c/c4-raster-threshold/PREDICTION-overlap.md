# C4c 사전 등록 예측 — 겹침이 왜 타일당 비용을 10배로 만드나

> **측정 전에 작성.** 2026-09-18.
> [C4 §6.8](RESULTS.md#68-타일-비용을-정하는-건-면적도-글자도-아니라-겹침이었다) 에서 열어둔 것.

## 모순

| 조합 (레이어 600 고정) | 타일당 µs | p50 |
|---|---:|---:|
| 100×100 · 글자O · **겹침** | 899 | 496 |
| 100×100 · 글자O · **안겹침** | **87** | **19** |
| 38×15 · 글자O · 겹침 | 779 | 487 |
| 38×15 · 글자O · 안겹침 | **148** | **31** |

**타일에 담기는 내용은 똑같다.** 같은 크기, 같은 글자, 같은 색.
박스가 화면 어디에 놓이느냐만 다르다. 래스터 **횟수**도 거의 같다(744 vs 798).

그런데 `RasterTask` 의 `dur` 이 10배다. **타일을 그리는 픽셀 작업량이 같은데 시간이 10배**라면,
그 시간은 그리는 일 자체가 아니라 **다른 것을 기다리는 시간**일 가능성이 크다.

## 가설

| # | 가설 | 내용 |
|---|---|---|
| **H1** | **오버드로 역압** | 600장이 같은 자리에 쌓이면 합성 때 같은 픽셀을 600번 덮어 그린다. GPU 가 포화되고, [Ganesh 로 GPU 래스터](../../track-a/a2-gpu-memory/RESULTS-source.md)를 하는 `RasterTask` 가 GPU 를 기다리느라 `dur` 이 늘어난다 |
| **H2** | **스레드 경합** | 겹칠 때 래스터 워커가 더 적게 쓰이거나 서로 막는다. `dur` 은 벽시계라 선점당하면 늘어난다 |
| **H3** | 실제로 일이 더 많다 | 겹치면 타일 내용이나 개수가 실제로 달라진다 (내 가정이 틀린 경우) |
| **H4** | 승격이 달라진다 | `spread` 를 주면 합성 레이어 수가 달라져서 애초에 다른 걸 재고 있었다 |

**H4 는 먼저 배제해야 한다.** 레이어 수가 다르면 나머지 논의가 무의미하다.

## 측정 설계

### A. 겹침을 연속 변수로 — 열(column) 수 스윕

`spread` 를 불리언이 아니라 **열 개수**로 바꾼다. 레이어 600 · 100×100 고정.

| cols | 한 자리에 쌓이는 깊이(대략) |
|---:|---:|
| 1 | 600 |
| 2 | 300 |
| 4 | 150 |
| 8 | 75 |
| 12 | 50 |

같이 기록: **합성 레이어 수**(H4 배제) · 래스터 **횟수** · 타일당 µs ·
`RasterTask` 를 실행한 **서로 다른 스레드 수** · 첫 래스터부터 마지막 래스터까지의 **벽시계 구간**.

**판정**
- 타일당 비용이 깊이에 따라 **매끄럽게** 변하면 → 겹침 자체가 원인 (H1/H2)
- 레이어 수가 cols 에 따라 변하면 → **H4. 앞의 결론부터 다시**
- 래스터 횟수가 크게 변하면 → **H3**

### B. GPU 래스터를 끄고 같은 걸 잰다

`--disable-gpu-rasterization` 으로 소프트웨어 래스터에서 cols=1 과 cols=12 를 비교한다.

**판정**
- GPU 를 끄니 10배 격차가 **사라지면** → **H1 채택** (GPU 역압)
- 소프트웨어에서도 10배면 → H1 기각. H2 쪽

### C. 합계와 벽시계를 비교한다

`dur` 의 **합계**와 첫~마지막 **벽시계 구간**을 같이 본다.

- 합계 ≫ 구간 → 여러 스레드에서 병렬로 돌았다는 뜻
- 겹칠 때만 합계/구간 비가 떨어지면 → 병렬도가 낮아진 것 (H2)
- 겹칠 때 구간도 같이 늘면 → 진짜로 오래 걸린 것

## 예측 요약

| # | 내 예측 |
|---|---|
| **H1** | ✅ **채택할 것** — GPU 래스터를 끄면 격차가 크게 줄 것이다 |
| **H2** | ⚪ 일부 기여 |
| **H3** | ❌ 기각할 것 — 타일 내용이 같으니 일이 더 많을 리 없다 |
| **H4** | ❌ 기각할 것 — `will-change` 는 그대로니 승격도 그대로일 것이다 |

래스터와 합성이 같은 GPU 를 쓰면 서로 막힌다.
