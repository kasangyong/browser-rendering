# C4b 사전 등록 예측 — 100×100 은 왜 안 켜졌나

> **측정 전에 작성.** 2026-09-18.
> [C4 §6.6](RESULTS.md#66-가림-가설도-내가-틀렸다) 에서 *"모른다"* 로 닫아둔 것을 다시 연다.

## 다시 보니 — 또 내 판정 기준이었다

part B 에서 100×100 이 **0/6** 으로 한 번도 안 켜졌다.
그런데 `rasterN`(래스터 **횟수**)을 보니 이렇다.

| 100×100 레이어 | rasterN 실측값들 |
|---:|---|
| 250 | **253, 253**, 1, 1, 1, 1 |
| 400 | 31, 1, 1, 1, **403**, 1 |
| 600 | 80, **603**, 1, 1, 1, 1 |

**253 / 403 / 603 — 레이어당 정확히 1회.** 새고 있었다.
다만 `rasterPer` 가 0.53~0.96ms 라 내가 정한 **5ms 기준**에 안 걸렸을 뿐이다.

> [§2 에서 "시간 말고 횟수를 세라"는 교훈을 얻어놓고](RESULTS.md#2-답--세는-것만으로-끝났다),
> 정작 켜짐/꺼짐 **분류는 시간으로** 하고 있었다. 같은 실수를 한 문서 안에서 두 번 했다.

## 남은 진짜 질문

횟수로 다시 분류하니 타일 하나를 래스터하는 비용이 이렇게 다르다.

| 박스 | 타일 크기 | 타일 1장 픽셀 | **타일당 래스터 비용** |
|---|---|---:|---:|
| 38×15 | 64×64 | 4,096 | **131~497 µs** |
| 100×100 | 128×128 | 16,384 | **17~39 µs** |

**픽셀이 4배인데 비용은 1/10 이다.** 이게 설명되어야 한다.

## 가설

| # | 가설 | 내용 |
|---|---|---|
| **G1** | **글자가 비용을 지배한다** | 박스마다 텍스트(`i % 100`, 9px)가 **한 줄씩** 있다. 글리프 래스터는 비싸고 단색 채우기는 싸다. 박스를 키워도 글자 양은 그대로니 **픽셀당** 비용이 떨어진다 |
| **G2** | 큰 박스가 서로 완전히 가려 **단색 타일**이 된다 | 320px 스테이지에 100×100 이 겹치면 위 박스가 아래를 덮는다. 완전히 덮인 타일은 `SolidColorAnalyzer` 가 단색으로 판정해 실제 그리기를 건너뛴다 |
| **G3** | 타일이 크면 **개당 고정비**가 분산된다 | 타일 1장당 오버헤드가 있고 픽셀 비용은 작다 |

## 판별 설계

하네스에 **글자 없는 모드**를 넣는다. 나머지는 그대로.
레이어 **600 고정**(양쪽 다 새는 구간), 4가지 조합 × 5회.

| 조합 | 글자 | 박스 |
|---|---|---|
| A | 있음 | 38×15 |
| B | **없음** | 38×15 |
| C | 있음 | 100×100 |
| D | **없음** | 100×100 |

**판정**

| 결과 | 결론 |
|---|---|
| B 가 A 보다 **크게 싸지고** D≈C 이면 | **G1 채택** — 글자가 지배한다 |
| 글자를 빼도 C·D 가 A·B 보다 훨씬 싸면 | G1 기각. G2 나 G3 |
| 겹치지 않게 배치해도 C 가 싸면 | **G2 기각** |

G2 는 **겹침을 없앤 배치**로 따로 확인한다 (스테이지를 키워 박스를 안 겹치게).

## 예측 요약

| # | 내 예측 |
|---|---|
| **G1** | ✅ **채택할 것** — 글자를 빼면 38×15 의 타일당 비용이 급감해 100×100 수준에 근접한다 |
| **G2** | ⚪ 부분적으로 기여 — 겹침이 심하니 일부 타일은 단색일 것이다. 다만 주된 원인은 아니다 |
| **G3** | ❌ 기각할 것 — 고정비가 지배한다면 타일이 4배 커질 때 비용이 **늘어야** 한다. 실측은 줄었다 |

**근거**: 38×15 박스는 9px 글자 한 줄이 높이 15px 를 거의 다 채운다 — 타일이 글자로 빽빽하다.
100×100 은 같은 글자 한 줄에 나머지가 전부 단색 채우기다.

**틀릴 수 있는 지점**: [§6.6 에서 가림 가설을 지어냈다가 틀렸다](RESULTS.md#66-가림-가설도-내가-틀렸다).
G1 도 그럴듯해서 세운 것이니 같은 함정일 수 있다. 그래서 **글자 유무를 직접 변수로 넣어** 잰다.
